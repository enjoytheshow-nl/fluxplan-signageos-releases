Fluxplan SignageOS

A Fluxplan screen that looks after itself

Fluxplan SignageOS turns a Raspberry Pi into a screen for Fluxplan: the day's planning in the lobby, or a room's schedule next to its door. Set it up once with your phone. No keyboard, mouse or separate signage software needed.

Download the latest image How to install

What it does

The screen shows the view you pick for it in the Fluxplan admin, and keeps running without anyone touching it.

Set up with your phone

The TV shows a temporary Wi-Fi network and a QR code. Join it, and a setup page in Dutch or English opens by itself.

Managed from Fluxplan

Pair a screen with a code, choose what it shows, then update, restart, shut down or reset it from the admin.

Updates itself

Debian, Raspberry Pi and player updates are installed at night. A new screen fetches the newest player as soon as it's connected.

Repairs itself

A page that freezes is reloaded, a stuck browser restarted, and in the end the whole Pi. After a power or network cut, it comes back by itself.

What you need

  • A Raspberry Pi 5 or 4 with its official power supply
  • A microSD card of 8 GB or more
  • A TV or monitor with HDMI, plus a micro-HDMI cable for the Pi
  • A network: Wi-Fi or a network cable
  • A Fluxplan you can sign in to as an admin

Where to get it

  • The SD card image: latest release, with a SHA-256 checksum to check your download
  • Raspberry Pi Imager can list it too: rpi-imager --repo https://enjoytheshow-nl.github.io/fluxplan-signageos-releases/imager.json

Installing a screen

It takes about ten minutes, most of it writing the SD card.

  1. Write the image to a microSD card

    Use Raspberry Pi Imager (Choose OS → Use custom) or balenaEtcher. Leave Imager's "OS customisation" off: the screen sets itself up.

  2. Start the Pi

    Put the card in the Pi, then connect the TV, a network cable if you use one, and lastly the power.

  3. Set it up with your phone

    Join the Wi-Fi network shown on the TV (Fluxplan-SignageOS-…) or scan the QR code. The setup page opens by itself, otherwise go to http://10.42.0.1. Choose Wi-Fi or a network cable, enter your Fluxplan address (for example demo.fluxplan.nl) and your country, then choose Save and connect.

  4. Pair it in Fluxplan

    The TV shows a pairing code. In the Fluxplan admin, open Narrowcasting, choose Pair screen, enter the code and pick what the screen shows. Within a minute, the screen shows it.

If something goes wrong while connecting, the TV says why and the setup network comes back, so you can try again. The full guide, in Dutch, is in the Help section of your Fluxplan admin.

Setting up in advance

Already know the Fluxplan address and Wi-Fi details? Then you can skip the phone step. After writing the card, open it on your computer and put a file called fluxplan.json next to FLUXPLAN-README.txt:

{
    "server": "demo.fluxplan.nl",
    "country": "NL",
    "wifi": { "ssid": "Office", "password": "secret", "hidden": false }
}

Leave out "wifi" when the Pi uses a network cable. The screen reads the file on its first start, then deletes it, because the file contains your Wi-Fi password.

Looking after a screen

In the Fluxplan admin, under Narrowcasting, each screen has a Player menu:

  • Update player: install a new version now instead of tonight.
  • Restart: restart the Pi.
  • Shut down: turn the Pi off, for example before you move it. To start it again, unplug the power and plug it back in.
  • Factory reset: the screen forgets your Fluxplan, its pairing and its Wi-Fi network, and goes back to setup.

If a screen is offline, you can also reset it from the SD card. Create an empty file called fluxplan-reset next to FLUXPLAN-README.txt, then put the card back in the Pi.

Security

Locked to your Fluxplan

The screen only opens its own Fluxplan, and only the views Fluxplan offers. Every other web address is blocked.

No way in

Nobody can log in to the Pi: the account is locked and SSH is off. The firewall only allows what setup needs.

Signed updates

Updates come from the signed apt repository at apt/. Key: fluxplan-signageos-archive-keyring.asc, fingerprint C57F 858F A9B2 7EE9 8EA3 13EF 5A39 CD8F 9F30 CF35.
